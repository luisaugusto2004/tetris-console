# 🎮 Console Tetris em C#

Este é um jogo de Tetris desenvolvido para o console utilizando C#. O projeto segue uma estrutura orientada a objetos e implementa a lógica básica do jogo de Tetris com recursos como movimentação de peças, rotação, detecção de colisões e limpeza de linhas.

## 🧱 Funcionalidades

- Peças caem automaticamente e colidem corretamente
- Rotação, movimentação lateral e queda acelerada
- Limpeza de linhas
- Sistema de Game Over

## 🎮 Controles

| Tecla           | Ação                        |
|----------------|-----------------------------|
| ⬅️ ←            | Mover para a esquerda      |
| ➡️ →            | Mover para a direita       |
| ⬇️ ↓            | Acelerar a queda           |
| ⬆️ ↑            | Rotacionar a peça          |
